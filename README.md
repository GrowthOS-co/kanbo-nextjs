# Kanbo

A task board for small teams: projects hold tasks on a three-column board (To
do, In progress, Done), tasks have an assignee, a due date and comments, and
each project shows how far along it is.

Built with Next.js (App Router), Drizzle ORM on SQLite, and Tailwind CSS.

## Getting started

```bash
npm ci
npm run db:setup   # creates kanbo.db, applies migrations, loads sample data
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

`npm run db:setup` can be run again at any time: it replaces everything in the
database with the sample team.

## How it works

- **Members** are the team: a name and an email. There is no login; the
  comment form asks who is writing.
- **Projects** have a name and an optional description.
- **Tasks** belong to a project and have a title, an optional description, an
  optional assignee and an optional due date. A task is `todo`, `in_progress`
  or `done`; anything else is refused. On the board each column lists its
  tasks oldest first, and the board can be filtered to one member's tasks or
  to the unassigned ones.
- **Comments** belong to a task and a member. Deleting a task deletes its
  comments; deleting a project deletes its tasks.
- A project's **progress** (tasks per status and the percent done) is worked
  out when it is shown, never stored.

| Path                    | What it is                                  |
| ----------------------- | ------------------------------------------- |
| `db/schema.ts`          | the tables                                  |
| `drizzle/`              | migrations, generated by `npm run db:generate` |
| `db/seed.ts`            | the sample team                             |
| `lib/`                  | project, task, comment and member logic, and its tests |
| `app/`                  | pages and form actions                      |

## Changing the database

Edit `db/schema.ts`, then:

```bash
npm run db:generate   # writes a new migration into drizzle/
npm run db:migrate
```
